# Product Vision

## Concept

AERION TEAM SIM is a working-title software-engineering career simulation.

The player joins a fictional high-expectation technology company and progresses from beginner developer to highly experienced engineer.

The game simulates what a normal IDE does not:

- business context;
- team communication;
- tickets;
- ambiguity;
- code reviews;
- QA feedback;
- security expectations;
- production incidents;
- technical debt;
- architecture discussions;
- increasing responsibility.

The player's real IDE remains the place where code is written, compiled, tested, debugged and refactored.

## Learning progression

Long term, the simulation may cover:

- Java fundamentals;
- object-oriented design;
- collections;
- exceptions;
- testing;
- Maven;
- SQL;
- JDBC;
- JPA / Hibernate;
- Spring Boot;
- HTML / CSS;
- TypeScript;
- Angular;
- API design;
- security;
- performance;
- JVM memory and GC;
- concurrency;
- virtual threads;
- observability;
- Git;
- CI/CD;
- distributed systems;
- architecture and technical leadership.

Technologies must appear because the simulated project develops a real need for them.

## Pedagogy

The player should experience a problem before being introduced to the tool or technique that solves it.

The progression should evolve from:

`ça fonctionne`

to:

`ça fonctionne et c'est testé`

to:

`c'est maintenable, sûr et observable`

to:

`est-ce la bonne architecture et pourquoi ?`

## Team

The virtual team is a core part of the experience.

- Claire — Product Owner
- Marc — Lead Java
- Inès — Lead Angular
- Nora — QA
- Sam — DevSecOps
- Julien — Architecte système

Characters should have consistent viewpoints and occasionally disagree for legitimate reasons.

## Prototype goal

Do not build the full career.

Validate one loop:

ticket -> IDE -> local tests -> git diff -> review -> correction -> acceptance

If that loop is not enjoyable, do not expand the product.
