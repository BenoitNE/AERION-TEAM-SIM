# Direction artistique — Prototype

## Intention

Application professionnelle chaleureuse, claire et moderne.

Référence principale : une interface de travail simple, lisible et respirante, avec des personnages cartoon qui apportent de la personnalité.

## Principe

**Less is more.**

Le ticket courant doit dominer l'écran.

Ne pas construire un dashboard d'entreprise rempli de métriques.

## Palette

- fond général : gris/bleu très clair ;
- surfaces : blanc ;
- typographie principale : bleu marine ;
- accent principal : turquoise/vert d'eau ;
- orange/rouge uniquement pour les alertes ;
- couleurs douces propres à chaque personnage.

## Layout principal

- navigation verticale compacte ;
- bandeau supérieur discret ;
- ticket large au centre ;
- équipe compacte à droite ;
- feedback de review affiché seulement après une soumission.

## Personnages

Style cartoon chaleureux.

Les portraits approuvés sont documentés dans `references/team-catalog-reference.png`.

Pour le socle technique, les avatars sont volontairement des placeholders typographiques.
Ne pas tenter de reconstruire les portraits en CSS.

Des assets individuels propres seront ajoutés ultérieurement.

## À éviter

- graphiques décoratifs ;
- cartes statistiques inutiles ;
- multiples widgets ;
- gradients omniprésents ;
- ombres fortes ;
- badges partout ;
- trois niveaux de navigation ;
- informations dupliquées ;
- esthétique cyberpunk / terminal / faux OS.
